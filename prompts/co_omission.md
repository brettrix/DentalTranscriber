# Co Omission Check

Your job: compare the sources with the list of entities already recorded, and report clinical statements that no entity covers: a symptom, history item, medication, allergy, vital, finding, test, radiograph, diagnosis, option, decision, discussion element, treatment, prescription, referral, next visit, or instruction.
- Quote each omitted statement exactly (one source line per quote) and suggest the item type it would be.
- A statement is covered if an entity records the same fact, even with different wording or citing a different line.
- Small talk, greetings, scheduling chatter and logistics without clinical content are not omissions.
- Report nothing if nothing is missing.
