# B0 Extraction Agent (single extractor)

Your job: in one pass, extract the problem registry (problems and relationships) and every item of every type in the attribute table below. Problem keys are `P1`, `P2`, …; relationship keys `R1`, …; item keys are short codes like `H1`, `S1`, `F1`, `D1`, `O1`, `X1` (any unique string). Items link problems with `problem_key`, and decisions/consent elements link options with `option_key` and decisions with `decision_key`, using keys from this same output.
